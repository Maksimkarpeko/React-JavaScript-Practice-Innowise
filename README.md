# React-JavaScript-Practice-Innowise

# 🚀 Getting Started

Follow these steps to get the project up and running on your local machine:

1. Clone the repository
   Bash
   git clone https://github.com/Maksimkarpeko/React-JavaScript-Practice-Innowise.git
   cd React-JavaScript-Practice-Innowise
2. Install dependencies
   Bash
   npm install

3. Run the development server
   Bash
   npm run dev

# Tech Stack

React 19 – UI Library
React Router - Client-side routing and layout management
CSS Modules + clsx – Component-scoped styling and conditional class management.
Redux toolkit - Efficient global state management
RTK Query - Advanced data fetching and caching layer
Leaflet - An open-source JavaScript library for mobile-friendly interactive maps
